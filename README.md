# 오늘 뭐 읽었어? v3

개인용 독서 다이어리 PWA입니다. 로그인 없이 IndexedDB에 데이터를 저장합니다.

## 실행
- `index.html`을 직접 여는 것보다 로컬 서버 또는 HTTPS 환경에서 실행하는 것을 권장합니다.
- GitHub Pages 또는 Netlify에 폴더 내용을 배포할 수 있습니다.
- 배포 후 브라우저 메뉴에서 홈 화면에 추가하면 PWA로 사용할 수 있습니다.

## 기능
- 여러 독서 공간 및 월간 독서 캘린더
- 작품 서랍: 제목/작가 필수, 표지/출판사/장르 선택, 연재/단행본 구분, 연재처, 읽기 시작일
- 표지 미등록 작품은 임의 색상 배경에 제목 표시
- 날짜별 독서 기록: 읽는 중/완독, 숫자 기반 진행량, 메모
- 연재작은 화, 단행본은 권과 쪽수(p) 입력
- 완독 작품은 1~5점 별점 기록
- 작품 서랍의 5점 작품 전용 색인 및 별점순 정렬
- 독서 공간별 배경 그라데이션과 앱 강조색 커스텀
- 월간 달력 PNG 저장, JSON 전체 백업/복원
- 지난 날짜 기록 입력 및 수정

## 저장 데이터
기록과 표지 이미지는 현재 브라우저의 IndexedDB에 저장됩니다. 브라우저 데이터 삭제 또는 기기 변경에 대비해 정기적으로 백업 파일을 내려받으세요.

- 팝업 대화상자 테두리를 현재 공간의 강조색으로 통일

## v6 변경 사항
- 단행본 독서 기록의 권수와 쪽수 입력을 한 줄의 2열 배치로 변경했습니다.
- 작품 정보에 선택 입력인 ‘이 작품을 읽는 이유’를 추가했습니다.
- 날짜별 독서 기록에 선택 입력인 ‘인상 깊은 문장 수집’을 추가했습니다.
- 완독 선택 시 선택 입력형 완독 노트(별점, 인풋 노트, 읽은 소감)가 펼쳐집니다. 세 항목 모두 입력하지 않아도 저장할 수 있습니다.
- 기록 열람 화면에서는 사용자가 작성한 항목만 표시합니다.


## v7 변경 사항
- 하단 문구를 에이미 로웰의 한국어·영어 인용문과 저자 표기로 교체했습니다.
- 선택 항목 표기를 제거하고 필수 입력 항목만 별표(*)로 표시합니다.
- 팝업은 고정된 높이를 유지하고, 내용이 길어지면 팝업 내부에서 스크롤됩니다.
- 텍스트 영역은 고정 높이로 설정하고 직접 크기 조절을 비활성화했습니다.
- 달력 날짜 칸과 달력 이미지 내 하루 기록 횟수 표시를 제거했습니다.


## v8 변경 사항
- 하단 명언을 가운데 배치하되 문장 영역은 왼쪽 정렬로 묶어 가독성을 높였습니다.
- 한국어 명언과 저자 표기를 키우고 행간을 조정했으며, 저자 표기를 ‘에이미 로웰 Amy Lowell’로 변경했습니다.
- 달력 날짜 칸의 일일 기록 횟수 배지를 렌더링 코드에서 제거했습니다.
- 달력 이미지 저장 렌더링에서도 날짜별 ‘n회’ 표기를 제거했습니다.
- 기존 day-count 스타일도 제거했습니다.


## v9 수정 사항
- 입력 폼에서 ‘선택’ 안내 문구를 모두 제거했습니다.
- 필수 입력 항목(제목, 작가)에만 별표(*)를 표시합니다.
- 모든 textarea 높이를 108px로 고정하고 크기 조절 손잡이를 제거했습니다.
- 내용이 길어질 경우 textarea 내부에서 세로 스크롤됩니다.
- Service Worker 캐시 버전을 v9로 갱신했습니다.


## v11 변경 사항
- 하단 명언과 저자명을 하나의 중앙 배치 블록으로 묶고 블록 내부는 왼쪽 정렬했습니다.
- 독서 기록의 읽은 분량(연재 회차 / 단행본 권수·쪽수)을 필수 입력으로 변경했습니다.
- 인상 깊은 문장을 여러 건 추가할 수 있고 각 문장별 페이지를 함께 저장합니다.
- 작품 서랍의 작품 등록/수정 팝업에 현재 활성 독서 공간 이름을 표시합니다.
- 페이지 상단의 백업 화살표 버튼을 제거했습니다. 설정 화면의 데이터 내보내기 기능은 유지합니다.


## v12 변경 사항
- 하단 명언 블록의 글자 크기와 행간, 위아래 여백을 축소했습니다. 문구 블록은 중앙에 놓이고 내부 문장은 왼쪽 정렬됩니다.
- 장르 예시에 BL을 추가하고, ‘서적 정보’를 ‘도서 정보’로 변경했습니다.
- 도서 정보에 선택 입력 키워드 항목을 추가했습니다. 쉼표로 구분해 저장하면 기록 열람 화면에 해시태그로 표시됩니다.
- 달력 날짜별 독서 기록 팝업에 작품 작가명을 표시합니다.
- 작품 서랍에서 표지 또는 제목을 누르면 해당 도서의 전체 독서 기록 페이지가 열립니다.


## v13 변경 사항
- 인상 깊은 문장 페이지 표기를 ‘쪽’에서 ‘p’로 변경했습니다.
- 작품별 도서 기록 페이지의 기록 카드와 메모 상자 배경을 더 옅게 조정했습니다.
- 달력 패널의 최대 너비를 줄이고 좌우·상하 여백을 늘렸습니다.
- PNG 달력은 좌우 각각 150px의 바깥 여백을 추가하고, 날짜 칸과 요일/제목/요약을 함께 이동해 넓은 캔버스로 저장합니다.


## v14 변경 사항
- 달력 바깥 패널의 폭은 아래 ‘이 달의 기록’ 패널과 동일하게 유지하고, 달력 요일/날짜 그리드는 최대 780px로 좁혀 중앙 배치해 좌우 여백을 넓혔습니다.
- 최근 6개월 독서 기록과 많이 읽은 장르 도넛 그래프를 데스크톱에서 나란히 배치하고 모바일에서는 세로로 배치합니다.
- 독서 성취 지표로 완독 기록 수, 평균 별점, 가장 자주 기록한 작품을 추가했습니다.
